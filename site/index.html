Architecture · stickman.animation/v2
Multi-actor choreography on one shared timeline.
Stage 2+ named stickmen with distinct vector accents (tie, hat, glasses, badge), synchronize cross-actor beats via emitCue and afterCue, blend consecutive clips with C1 Hermite continuity, solve bilateral push contact, and address semantic stage anchors. Embed scenes directly with the <stickman-player> Web Component and bindScrollTimeline scroll-linked playback.
106 runtime actions53 geometric propsemitCue / afterCue syncC1 Hermite joins<stickman-player> + scroll
Every frame is a pure 30 fps function of compiled v1/v2 data with zero model-weight training or remote runtime calls. Catalogue previews remain distinct from runtime motion revisions, and arbitrary unscripted contact physics or cross-slide continuity remain separate qualification work.
